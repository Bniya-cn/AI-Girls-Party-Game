# 星屿骰夜

一张牌桌、六个场地、三轮对局。可独自与电脑练习，也可由 2–5 位真人入座。桌上奖金牌和筹码均用于游戏计分，没有充值、下注或提现。

## 运行与测试

需要 Node 22.12 或更新版本。在游戏目录运行：

```sh
npm ci
npm run build
npm test
npm start
```

打开 [本机游戏入口](http://127.0.0.1:4321/)。服务只监听本机回环地址。测试两个真人席位可分别使用普通窗口和隐私窗口，通过房间码入座；默认配置不能让异地设备直接加入。macOS/Linux 可用 `PORT=4326 npm start` 选择其他端口。Ctrl+C 停止。

## 如何玩

大厅「单人派对」一键开启一场完整三轮的私有对局，电脑自动行动。两人桌每轮开始时会投八颗中立骰。「开一桌」进入真人房间，房主可设置座位数、选择扩展与拼板位置，全员准备后开局。大厅和桌边都有短教程，桌边指引依真实骰面更新，可以跳过和重新开启。

每轮每人取回七小一大八颗骰子，保留剩余筹码并领取两枚。掷出全部手骰，挑一个点数，将所有同点骰放到对应场地。掷后可花一筹码跳过。点亮牌面即可投放，也可用 Tab 和 Enter 或空格完成操作。

- **奖金与实力。** 90 张奖金牌洗匀，每轮按顺序抽六对。两张合计越高，场地编号越高；总额相同再比较大牌。大骰实力为 2，小骰为 1。在每个场地，实力相同的全部阵营退出竞争，剩余前两名依次拿大牌、小牌。中立和灰骰分别参与排名，归于它们及无人领取的牌都送回牌堆底。
- **下一轮。** 第 1、2 轮派奖后可展开六场明细，由房主点击继续。下一轮从高编号场地优先确定先手，重新发牌并在两人桌重投中立骰。
- **终局。** 第三轮后，持有的奖金牌面额加上剩余筹码（每枚 1 万）构成总分。金额相同时比较奖金牌张数与筹码数之和，两项仍同则并列获胜。记分面板可查看三轮逐场账目。
- **本作桌规。** 首轮由房主先手。若虚拟阵营拿到高额牌，先看同场另一张是否由玩家领取，再看下一低编号场地；整轮无人领牌则由上一先手的下一席开始。这是对无人可执先情形的线上处理。电脑与真人都是玩家席位，中立与灰骰只参与场地排名。
- **可选 F1。** 房主可将一块灰骰板固定在任一场地留用三轮，每轮重置五组灰骰。把自己的同点组放到该场地会触发取一整组灰骰，再选目的地。灰骰到达不再次触发。练习时从大厅教程最后一页可单独开带 F1 的三轮局。基础桌与旧 F1 入口继续使用原来的发牌方式。

## 派对桌怎么玩

**骰子落到哪，就在该场地玩小游戏。小游戏的奖金、罚款和移骰当场生效。** 六个主场各自的两张奖金牌按轮末实力发放。本作的即时奖罚属于星屿派对桌规。

- **单人派对**把藏数、猜高低、失运、整组灰骰、盲盒、任选星签挂满六场。掷骰后，亮起的场地会显示现在落下整组骰子的暂定名次，以及会发动哪种效果。
- **随机三板**每轮从八块实体板中选三块，随机翻面和落位到 1–3 号，允许跨轮重现。**自选扩展**可以把 0–6 块挂到指定场地，配置三轮固定，同板两面互斥。
- **单练选中板面**在自选界面打开。教学首掷保证有五颗 1 点，点 1 号场就能尝试这面。后续正常掷骰。基础练习、旧 F1 教程和三板样例也可直接进入。
- **真人房**由房主在桌面设置选六场派对、随机或自选。参与者只收到自己有权看到的秘密信息。待选操作可随席位重连恢复。

| 实体板 | 两面小游戏 |
| --- | --- |
| A | A1 你暗藏 1–3 枚，左邻猜数。A2 黑骰同点或合计 7 即领取当前奖池，否则奖池升格。 |
| B | B1 落骰者召回未被封锁的黑骰，掷后任选支援位置。B2 猜下次点数总和高低，也可收手领取当前格。平局判猜错，桌上显示实际胜率。 |
| C | C1 首位主动入场达到至少五点实力，当场领 10 万。C2 按落骰后的实力找出最低的全部玩家，各当场缴 5 万，零骰也参与比较。 |
| D | D1 按占据主场的数目发筹码或奖金。D2 独自领先可取标，保持领先时每回合可定面，并发动目的板。 |
| E | E1 选择封锁的其他主场，换封场推进奖励轨。E2 对手将手骰交到吧台，触发者收回自己的押骰。 |
| F | F1 将一整组灰骰移到一个开放主场。F2 从开放主场取一灰填槽领钱、领筹码、改点放骰或收回己骰。 |
| G | G1 左邻把六枚奖片暗分成两只非空的盒子，落骰者只看每盒枚数，开盒当场领奖。G2 主场与副板争夺分别计实力，调动完按当前副板名次领差额，每席每轮最高 6 万（次名 3 万）。 |
| H | H1 选当次骰占对应点槽，旧骰回主场，每席每点槽每轮首次占据即领奖。H2 两枚星签选一枚。1–3 领奖，4 借用其他已挂且开放的板，5 调整己骰，6 占金框并归还旧骰。每席每轮首次占金框即领 6 万。 |

**资金和互动边界。** 首轮桌面、以后两轮预留和银行分别有 12、24、54 张纸币。自选与随机桌的额外现金取自银行。罚款优先按足额交易，玩家可在可行的纸币、已有筹码和纸币找零方案之间选择；无法足额交易时按实际可交割的最高金额扣款。私人收据保留支付和找回的面额。B1 黑骰在主场提供实力，不能收为手骰。E1 同时限制进出，若所有掷骰都指向封场便免费让过。H2 的借用不会生成实体骰，也不能再选 H2；例如借用 C1 并未放入新骰，因此不会凭空获得五星奖。

## 派对桌的试玩验收

固定种子回归会枚举 448 种合法三板组合，每种打完三轮。另用 100 局六场派对统计实际选择空间。本版 2,851 次选区中，2,259 次有至少两个合法落点。可在游戏目录执行 `node --test test/party.test.js` 复现。模拟席位只能用自己的投影视图决策。

真人试玩关注三个具体时刻。第一次掷骰后，玩家能否说明自己为了哪个小游戏放弃了另一处奖金；猜高低时，能否根据当前奖励和胜率决定收手；盲盒揭晓或罚款后，能否从桌面反馈说明自己赚了或付了多少。若这三处仍然容易机械点过，应优先调整选区提示、对手的选择和结果停留时间。

## 实现与素材

纯规则在 `rules/`，服务端随机、房间、回执与电脑决策在 `server/`，三维牌桌、训练提示与结算界面在 `web/`。服务端只投影当前奖池和已发生的分账；新动作须匹配席位、阶段和修订号。重发同一已提交动作可取回回执，不会再次掷骰或派奖。房间保存在内存，同一窗口可在服务进程运行时恢复席位；服务重启后无法续局。

公开版自带程序绘制的美术。自备且有权使用的 WebP 可放在 `web/public/art/` 后重新构建；各槽位独立回退。环境与大厅使用 evening、host，牌面用 venue-1 到 venue-6，座位用 seat-deepseek、seat-claude、seat-gemini、seat-gpt、seat-qwen；已开放的扩展按小写编号加载，如 a1、b2、h1。共享配件用程序绘制的透明图集。自有 glTF/GLB 可按 `web/models.js` 注册；缺失时保留几何模型。
